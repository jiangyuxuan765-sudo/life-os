# Life OS

一个简洁、有秩序的个人网页工作区。设计参考采用深色底、荧光绿焦点、圆角卡片和浅色摘要面板。无需安装依赖。

## 启动

在本目录运行：

```sh
npm start
```

或：

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

浏览器打开 http://localhost:4173。由于使用 ES Modules，请通过本地服务访问，不要直接双击 HTML。

## 分享交互演示

演示入口为 [Life OS 交互演示](https://jiangyuxuan765-sudo.github.io/life-os/?demo=1)，本地预览使用 `http://localhost:4173/?demo=1`。五个板块使用示例内容，可以体验新增、修改、删除、筛选和专注计时。演示修改只存在于当前页面内存，刷新或重置后恢复示例；不保存到浏览器业务缓存，也不连接个人账号或云同步。

分享时保留 `?demo=1`，可附加页面位置，例如 `?demo=1#record`。不带该参数的原网址仍为个人正式版，继续提供本机保存、邮箱登录与云同步。验收进度见 [QA-CHECKLIST.md](QA-CHECKLIST.md)。

## 五个工作页

| 页面 | 核心功能 |
| --- | --- |
| 决策 | 新建/编辑问题、方案比较、记录理由、决定/搁置、筛选、删除与撤销 |
| 监控 | 每日能量/睡眠/运动/专注录入、7天趋势、历史记录修改 |
| 周计划 | 前后换周、按日安排、任务编辑、本周目标管理与完成度 |
| 执行 | 新建/编辑/完成任务、状态筛选、删除撤销、25分钟专注计时 |
| 记录 | 新建/编辑/删除记录、标签、关键词搜索、反思提示 |

桌面使用左侧导航，手机使用底部五栏导航。顶部提供当天日程、全局搜索（⌘/Ctrl+K）和当前页快速新增。周计划与执行页共享任务。在个人正式版中，专注计时跨页面、刷新继续，完整完成一次计时会更新当天专注分钟数；演示中的计时与指标仅在当前页面内存中变化。

## 文件

- `index.html`：应用壳层、导航与弹窗容器。
- `styles.css`：桌面、平板、手机布局与视觉样式。
- `app.js`：页面渲染、hash 路由、交互与表单。
- `store.js`：示例数据、日期工具、数据校验与各账号本机缓存。
- `cloud.js` / `cloud-ui.js`：Supabase 认证、同步协调与账号面板。
- `sync-core.js`：三方合并、删除传播与冲突备份内容。
- `supabase/schema.sql`：用户隔离与版本检查保存接口。
- `.github/workflows/deploy.yml`：GitHub Pages 自动部署。
- `ARCHITECTURE.md`：信息架构、导航和共享实体说明。
- `DATA.md`：数据保存方式和产品边界。
- `QA-CHECKLIST.md`：验收场景与验证记录。

个人正式版首次加载的任务、指标和文字都是可修改的示例。未配置云端时，正式版数据只保存在当前浏览器；演示版不使用该保存机制。

## 跨设备使用

采用 GitHub Pages + Supabase 方案，配置完成后电脑和手机访问同一网址、使用同一邮箱登录，即可同步五个板块。默认点击 Supabase 邮件中的登录链接（Magic Link）；免费项目无需修改模板。若项目按控制台要求配置自定义 SMTP 或升级并定制 OTP 模板，也可输入邮件里的数字验证码。部署步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。没有真实项目配置时，界面显示「云同步待配置」；实际跨设备结果仍需部署后验证。

- 每账号单独保存，数据库行权限只允许本人读取。
- 在需要登录的设备和浏览器打开邮件链接；电脑和手机可分别申请登录邮件，使用同一邮箱进入同一账号。
- 修改先保存在本机，700ms后发起同步；前台每15秒及页面重新聚焦时获取最新内容。
- 使用版本检查和三方合并，避免旧设备覆盖整个工作区。冲突内容在本机保留备份，可从账号面板导出。
- 旧版本数据可导出JSON，在发布网址登录后导入。不同网址之间不会自动搬移 localStorage。
- 专注倒计时只在启动它的设备运行；完成后的专注分钟数参与数据同步。
- 不接入真实健康设备或外部日历。首次配置需要自己的 Supabase 项目；SMTP、免费额度、地区可达性以服务商当前情况为准。
